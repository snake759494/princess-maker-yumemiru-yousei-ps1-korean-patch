# 프린세스 메이커 ~꿈꾸는 요정~ 번역 지침

모든 명령은 저장소 폴더에서 실행합니다. 원문은 저장소에 없으므로 먼저 `python tools/prepare.py`로 원본 디스크에서 원문 목록(`text/src/`)을 만들어야 대조할 수 있습니다.

## 파일
- 이벤트 대사·메뉴(`PM.EVX`): `text/ko/evx_NN.json` = `{"번호": "한국어"}`. 번호는 `text/src/evx_NN.json`의 `i`와 같습니다. 같은 원문이 여러 곳에 있으면 한 번만 번역하면 모두 바뀝니다.
- 실행파일 문자열(`PM3.EXE`): `text/ko/exe.json` = `{"메모리 주소": "한국어"}`. 주소·파일 오프셋·최대 길이는 `text/exe_index.json`에 있습니다.
- UTF-8, `ensure_ascii=False`로 저장합니다.

## 반드시 지킬 형식
1. `{E}`는 제어 코드(ESC)의 시작입니다. `{E}`와 바로 뒤의 ASCII 인자는 한 글자도 바꾸지 말고 같은 순서로 둡니다.
   - `{E}%frstname`(딸 이름), `{E}%fmlyname`(성), `{E}%neko`(고양이 이름), `{E}%money`, `{E}%100` 같은 변수
   - `{E}#04{E}#` 아이콘, `{E}[01 … {E}]` 선택지(바로 뒤 숫자까지 코드), `{E}d32,56` 좌표, `{E}f0` 색, `{E}_41` 표정, `{E}n` `{E}c` `{E}k` 등
2. 줄바꿈 `\n`의 개수와 위치는 원문과 같게 둡니다. 대사는 게임이 자동으로 줄을 바꿉니다.
3. `fit: true` 항목은 자리를 옮길 수 없으므로 바이트 길이가 `max` 이하여야 합니다(한글·전각 2바이트, ASCII 1바이트, `{E}` 1바이트).
4. 능력치 표처럼 게임이 정해진 바이트 위치에 숫자를 써 넣는 문자열(`{E}k{E}f`가 들어간 것)은 앞쪽 이름 부분의 바이트 길이를 원문과 똑같이 맞춥니다. 예: `자존심  :`(9바이트), `피로도:`(7바이트).
5. 쓸 수 있는 문자: 한글 완성형, ASCII, Shift-JIS에 있는 전각 기호(…・「」『』～●■★♪ 등). 한글 자모 단독, ♥ 같은 Shift-JIS 밖 기호, 가나·한자는 쓸 수 없습니다.
6. 검사: `python tools/tcheck.py NN`, 남은 일본어 찾기: `python tools/survey.py`.

## 문체
- 우즈(집사 요정): 주인님(아버지)께 공손한 존댓말. 아가씨(딸)에게도 존댓말. 귀엽고 수다스러운 말투.
- 딸: 아버지에게 반말("아빠"). 나이에 맞게 밝고 자연스럽게.
- 그 밖의 인물은 원문의 말투(거친 말, 귀부인 말투, 노인 말투)를 살립니다.
- 의성어·감탄사는 한국어로(후후, 에헤헤, 냠냠).
- 이름 변수 뒤 조사는 문장을 바꿔 피하고, 어쩔 수 없으면 `이(가)`, `은(는)`, `을(를)`, `와(과)`로 씁니다.
- **기계 번역 금지.** 의역은 허용하지만 누락은 하지 않습니다.
