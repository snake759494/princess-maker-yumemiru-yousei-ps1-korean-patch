# 기술 설명

대상: PS1 일본판 『プリンセスメーカー ゆめみる妖精』(SCPS-10032), 데이터 트랙(Track 1, MODE2/2352) + CD-DA 음악 트랙(Track 2). 패치는 Track 1만 바꿉니다.

## 디스크

| 파일 | 내용 | 패치 |
| --- | --- | --- |
| `PM3.EXE` | 본편 실행파일 | 실행파일 문자열 102개, 이름 입력표, 한글 글꼴 훅 + 글리프 1,032자 |
| `PM.EVX` | 이벤트 스크립트(대사·메뉴·선택지) | 문자열 교체·재배치 |
| `PM.DT0` | UI 그림(4bpp) | 그림 21장 교체 |
| `PM.PCC`, `PM.MAP` | 캐릭터·배경 | 글자 없음 |

`tools/iso.py`가 ISO9660을 읽고, `tools/disc.py`가 파일을 같은 자리에 쓰거나(크기가 같을 때) 디스크 끝에 옮겨 디렉터리 레코드를 고칩니다. 섹터 EDC/ECC는 `tools/cdsec.py`가 다시 계산합니다. `PM3.EXE`가 커져서 디스크 끝으로 옮겼기 때문에 결과 BIN이 원본보다 536,256바이트 큽니다.

## 한글 글꼴

게임은 BIOS 한자 ROM 함수(Krom2RawAdd)로 Shift-JIS 코드에 해당하는 16×15 1bpp 글리프를 받아 그립니다(`PM3.EXE` 0x80058b4c의 호출).

- 번역에 쓰인 한글 음절 1,032자에 Shift-JIS 사용자 정의 영역 코드(0xF040부터, 트레일 0x7F 제외)를 차례로 붙입니다(`build.py`의 `Charset`, `hook.code_for_index`). 게임의 표시 폭 함수(0x80076938)는 리드 0x81~0x9F만 2바이트 문자로 보고, 그 밖에서는 0xDE/0xDF 바이트를 반각 탁점으로 여겨 폭 0으로 셉니다. 그래서 트레일이 0xDE/0xDF인 코드에 걸린 음절(넋넌룹뤄성세자작텐템)은 표 끝의 다른 코드로 옮겨 씁니다. 옛 코드 자리에도 같은 글리프를 남겨 두어, v1.2 이전 세이브에 저장된 이름도 같은 글자로 보입니다(v1.2까지는 「세」가 0xF2DF여서 이름 패널의 「세나」가 「세ㄴ」으로 잘렸습니다).
- 호출 지점을 훅 함수로 바꿉니다. 코드가 0xF040 이상이면 붙여 둔 한글 글리프 표의 주소를, 아니면 원래 함수를 부릅니다(`tools/hook.py`).
- 훅과 글리프 표는 EXE 끝에 붙이고, 새 엔트리 스텁이 시작할 때 0x80010000~0x80040000(쓰이지 않는 RAM)으로 복사한 뒤 원래 엔트리로 넘어갑니다.
- 자동 줄바꿈 폭 계산 두 곳(0x80054568, 0x80054ddc)도 한글 코드를 전각으로 세도록 고쳤습니다.
- 글리프는 갈무리11 12px를 확대·축소 없이 1bpp로 렌더합니다(`tools/kfont.py`). 메인 화면의 이름 패널과 작은 날짜 칸은 글리프의 왼쪽 12열만 그리므로, 폭이 14인 갈무리14를 쓰면 「나·하」의 ㅏ 획이 잘립니다(v1.0의 문제).

## 이벤트 스크립트 `PM.EVX`

32KB 블록의 나열입니다. 블록 = 헤더 16바이트(`EVX0`, 크기) + 문자열 영역 + 바이트코드. 문자열은 `01 lo hi` 명령(블록+16 기준 16비트 오프셋)으로 참조됩니다(`tools/evx.py`).

- 번역이 원문보다 짧으면 제자리에 넣고, 길면 비운 원문 자리·블록 꼬리의 빈 공간으로 옮긴 뒤 참조를 모두 고칩니다. 참조를 확실히 찾을 수 없는 문자열은 제자리에만 넣습니다(`fit`).
- 이번 판: 제자리 353, 재배치 12,702, 원문 유지 0.
- 능력치 표는 게임이 문자열의 고정 바이트 위치에 숫자를 써 넣으므로 라벨 바이트 길이를 원문과 같게 맞췄습니다.
- 원문 반각 가타카나의 탁점·반탁점(ﾞﾟ)은 앞 글자와 합쳐져 칸을 차지하지 않습니다. 그래서 「ﾌﾟﾗｲﾄﾞ」(9바이트)는 화면에서 7칸입니다. 바이트 위치가 고정된 표 문자열은 길이를 지키면서 폭을 맞추려고, 폭이 없는 색 코드 `{E}f0`(3바이트)로 남는 바이트를 채웠습니다. 연말 「능력치 증감」의 오른쪽 열은 줄바꿈 없이 폭으로 줄이 나뉘므로, 짧아진 줄 끝에 줄바꿈을 넣었습니다.
- 외자(gaiji) 코드 `{E}#09{E}#`, `#10`~`#1B` 중 한자 그림은 한글로 바꾸고, 하트·땀 등 아이콘은 그대로 둡니다.

## 실행파일 문자열

`text/exe_index.json`의 주소·파일 오프셋·최대 길이에 맞춰 같은 칸에 씁니다. 세이브 제목, 아버지 신분, 아이템 설명, 상점·병원 안내 등.

## 이름 입력

이름 입력표(히라가나 0x800a0e94, 가타카나 0x800a12b4)의 가나 칸을 이름에 자주 쓰는 한글 음절 161자로 바꿨습니다. 「英/ｶﾀｶﾅ/ﾋﾗｶﾞﾅ」 전환 버튼은 「영/다음/이전」입니다(`tools/namein.py`).

## 그림 `PM.DT0`

청크 형식(`tools/gfx.py` 머리 주석). 모두 4bpp이고 팔레트는 그대로 두고 인덱스만 바꿉니다.

| 스크립트 | 그림 |
| --- | --- |
| `gfx_a.py` | 메인 메뉴 버튼, 스케줄 항목표, 페이즈·일 표시, 달력 |
| `gfx_b.py` | 별자리·혈액형·아버지 신분 표, 상태 화면 라벨 |
| `gfx_c.py` | 선물·아이템·요리·그림 이름 라벨 |
| `gfx_d.py` | 월·요일 달력 칸, 휴일 배너, 페이즈 시작·완료 배너, 타이틀 메뉴 |

달력 칸(006·008)은 PNG로 뽑으면 폭 64로 보이지만 실제 텍스처는 폭 32(한 PNG 행 = 실제 두 행)이고 칸은 32×16입니다.

## 확인

DuckStation을 화면 밖에서 띄워 GDB 서버로 메모리를 읽고, 창 메시지로 키를 보내며 화면을 찍었습니다(`tools/emu.py`, `srv.py`, `c.py`). `tools/survey.py`는 EVX·EXE에 남은 일본어 문자열을 셉니다. 게임 코드를 디스어셈블한 결과물은 저장소에 넣지 않았습니다(`mdis.py`, `xref.py`는 분석용 도구).
